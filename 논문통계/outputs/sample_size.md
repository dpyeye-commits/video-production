# H5 다집단 SEM 표본 크기 산정 (semPower)

다집단 CFA 모형: 3요인 × 3지표, 2집단, df = 48.

## 모형 적합도 검정 — 필요 총 N

| 탐지 RMSEA | 검정력 80% | 검정력 90% |
|---|---|---|
| .05 (close fit 변별) | **249 (125/집단)** | 305 (153/집단) |
| .08 (mediocre fit) | 98 | 120 |

## 현재 N=200 사후 검정력
- RMSEA=.05 탐지: .669 (다소 부족)
- RMSEA=.08 탐지: .996 (충분)

## 측정 동일성(scalar) 위반 탐지
- ΔRMSEA=.02 → N≈5,674 / ΔRMSEA=.01 → N≈22,754
- ※ df차=6에서 ΔRMSEA 기반 검정력은 미세 위반 탐지에 비현실적으로 큰 N을 요구. 실무는 **ΔCFI < .01** 기준 사용 권장 → 모형적합 N(~250)이 실질 기준.

## 권고
- **목표 표본 N ≈ 250 (집단당 125)** — 80% 검정력으로 RMSEA=.05 변별.
- 여유 확보 시 N ≈ 305 (90%).
- 경험칙(N≥200·모수당 10명)도 충족.
- **최종 표본 = H2(상호작용)·H4(매개)·H5(SEM) 요구 N의 최댓값**으로 확정 권장. H5 기준 ~250이 하한선.
